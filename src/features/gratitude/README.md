# gratitude · Gratitud

Cada día invita a anotar tres cosas por las que dar gracias (se pueden añadir más). Las entradas se guardan en `gratitude_entry` (migración `0002_gratitude_gospel.sql`) y se pueden editar o borrar, con deshacer.

- Pantalla `/gratitude`: lo de hoy, la racha de días seguidos y el historial por días.
- Tarjeta en Hoy: lista del día y campo rápido para añadir.
